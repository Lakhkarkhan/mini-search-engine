    BM25 Ranking Parameters

    BM25 (Best Matching 25) balances term frequency with diminishing returns and document length normalization.

    k1 = 1.5 (Term Frequency Saturation)

    Controls how quickly repeated occurrences of a search word achieve diminishing returns so a word appearing 10 times isn't 10x more important than appearing once.

    b = 0.75 (Length Normalization)

    Penalizes verbose documents so longer texts that naturally contain more words don't overpower concise, highly relevant documents.

    Search Query Syntax Reference

    Mini Search supports rich query syntax directly in the search bar. Click any "Try It" button to test.

    Query Type Syntax Description Example Action
    Disjunction (OR) term1 term2 Matches documents containing either word; highest BM25 score first. python testing
    Conjunction (AND) +term1 +term2 Both words are strictly required in the matching document. +inverted +index
    Negation (NOT) term -exclude Excludes any document containing the specified word. search -engine
    Exact Phrase "word1 word2" Matches only when words appear side by side in that exact order. "machine learning"
    Excluded Phrase -"bad phrase" Excludes documents that contain that exact contiguous phrase. python -"web framework"

    How This Search Engine Works

    1. Analysis & Tokenization: Input text is tokenized into word positions, lowercased, stripped of common English stopwords, and reduced to root forms using a lightweight stemmer (e.g. running → run).

    2. Inverted Index with Positions: Rather than scanning documents sequentially, an inverted index maps each term to its list of occurrences (document IDs and exact word positions). This makes phrase queries accurate and sub-millisecond fast.

    3. BM25 Relevance Scoring: Uses the industry-standard Okapi BM25 formula to rank candidates based on Inverse Document Frequency (rare terms matter more) and Normalized Term Frequency.
